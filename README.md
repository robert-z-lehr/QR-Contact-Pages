# SIST — Structured Idea Stress Test

A two-page printable and browser-friendly feedback instrument for understanding, challenging, and improving early-stage ideas.

SIST guides an evaluator through a progression of:

**Understand → React → Stress Test → Improve**

It is designed for products, services, research concepts, policies, interventions, tools, prototypes, business ideas, and other concepts that benefit from structured external critique.

## Live page

[SIST](https://robert-z-lehr.github.io/SIST/)

## Current structure

**Page 1 — Understand + React**
- Understand the idea
- Existing landscape + gap
- Who, where + when?
- Initial reaction + personal demand

**Page 2 — Stress Test + Improve**
- Features + friction
- Scope, boundaries + limitations
- Failure points + assumptions
- Evidence + validation
- Market, business + scale
- Change it + next step
- Core / Invariant
- Questions, Suggestions + Notes

The form is formatted for US Letter printing and can also be completed in a browser before printing or saving as PDF.
